# Lab 1 Tinkerbelle Remix

This version of Tinkerbelle was updated for the second iteration of Lab 1.

## Changes

- Added a slow blue breathing light for the laptop's normal sleep state.
- Added a faster red breathing light for an urgent warning state.
- Added controller buttons to start and stop both light states.
- Added WebSocket events so the controller can trigger both effects on the
  connected phone.

See the main `README.md` in this folder for installation and startup
instructions.
